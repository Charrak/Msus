# Tägliche Bedienung

## Der Startbildschirm

```text
EINFACHSTART 91

21:35 Uhr
Dienstag, 3. November                [ Akku 85 % ]

MEINE LIEBSTEN

[ FOTO ] [ FOTO ]
SOHN       TOCHTER

[ TELEFON ]      [ NACHRICHTEN ]
[ WHATSAPP ]     [ FOTOS ]
[ KAMERA ]       [ HILFE ]

[ NOTFALL – HILFE RUFEN ]
```

- **Uhr, Datum, Wochentag und Akku** stehen oben.
- **Kontakte:** Ein Tippen auf die ganze Karte ruft die Person direkt an. Das große Telefonsymbol macht die Funktion zusätzlich deutlich.
- Leere Plätze zeigen ein „+“ und führen nach PIN-Eingabe in die Kontaktverwaltung.
- Auf dem Pixel 8 passt der Bildschirm ohne Scrollen. Auf sehr kleinen Displays kann normal gescrollt werden; es gibt keine versteckten Wischgesten.

## Die großen Funktionstasten

| Taste | Was passiert |
| --- | --- |
| **TELEFON** | Große Auswahl: Anrufen, Anrufliste, Telefonbuch |
| **NACHRICHTEN** | SMS-App lesen oder neue SMS schreiben |
| **WHATSAPP** | Öffnet WhatsApp, falls installiert |
| **FOTOS** | Öffnet die Galerie / Bilderansicht |
| **KAMERA** | Startet die Kamera-App |
| **HILFE** | Zeigt den festgelegten Angehörigen und ruft ihn nach Bestätigung an |
| **NOTFALL – HILFE RUFEN** | Öffnet zuerst eine deutliche rote Bestätigungsseite |

## Notfall

1. Rote **NOTFALL**-Taste antippen.
2. Auf der Bestätigungsseite stehen der hinterlegte Notfallkontakt und dessen Nummer.
3. **„NOTFALLKONTAKT ANRUFEN“** oder – falls aktiviert – **„112 ANRUFEN“** antippen.
4. **Es wird niemals automatisch gewählt.** Jeder Anruf braucht eine bewusste, große Berührung.

## Zurück

- Jeder Bildschirm hat oben links einen großen **ZURÜCK**-Button. Viele Seiten haben zusätzlich unten eine große Zurück-Taste.
- Auf dem Startbildschirm zeigt der Zurück-Button die große Meldung **„Sie sind bereits auf dem Startbildschirm.“** Die App wird nicht verlassen.
- Auch die Android-Zurück-Taste wird auf dem Startbildschirm abgefangen, damit kein unbeabsichtigtes Verlassen passiert.
- Externe Apps (Telefon, SMS, Galerie …) werden nur nach einem deutlichen Tap geöffnet; mit deren Zurück-Taste kommt man zu EinfachStart 91 zurück.

## Ruhe und Übersicht

- Keine Animationen, keine Werbung, keine Pop-ups ohne Anlass.
- Keine kleinen Schaltflächen: alle Touchflächen sind mindestens 80 × 80 dp.
- Hoher Kontrast: dunkle Schrift auf hellem Grund; blaue, grüne, orange und rote Tasten mit weißer Schrift.
- Keine verschachtelten Menüs: Die Verwaltung ist eine einzige, scrollbare Seite; der Kontakteditor ist genau eine Ebene tief.
